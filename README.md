Workplace Writing II: Summary Fidelity and Report Scaffolding
Step 1 — Understanding Summary Fidelity
Summary fidelity means accurately representing the original source without changing its meaning.
A faithful summary should not:
•	Add new facts
•	Change the meaning
•	Remove critical information
•	Exaggerate conclusions
•	Invent statistics
•	Present assumptions as facts
•	Create unsupported recommendations
Important Principle: A shorter summary is useful only when it remains faithful to the source.

Step 15 — Student Reflection
1. What does summary fidelity mean?
Summary fidelity means accurately representing the original source without changing its meaning or adding unsupported information.
2. What is the difference between an omission and an invention?
An omission means leaving out information that was present in the source. An invention means adding information that was not supported by the source.
3. Why must numerical information be checked separately?
Numbers can easily be changed or misunderstood by AI, so each figure should be compared directly with the original source.
4. Why should source limitations be included in a summary?
Limitations explain what the source does not measure or prove. Including them prevents readers from drawing unsupported conclusions.
5. What is a report scaffold?
A report scaffold is a structured framework containing the main sections of a report before all factual content is finalised.
6. Why should report structure be separated from factual content?
This prevents headings or planned sections from being mistaken for verified facts.
7. What is the purpose of a [VERIFY] placeholder?
It shows that specific information needs to be confirmed before the report is finalised.
8. Can a concise summary still be misleading? Explain.
Yes. A summary can be short but misleading if it removes important facts, changes figures, hides limitations or adds unsupported conclusions.
9. How did peer review improve your summary?
Peer review helped confirm that the figures were correct, the source meaning was preserved and no unsupported conclusions were included.
10. Why should an AI-generated management report be reviewed before use?
AI may omit information, misunderstand the source or create unsupported claims. Human review is necessary before the report is used for management decisions.
